TRC20 USDT.I

Project Whitepaper

1. Overview

TRC20 USDT.I is an independently issued fungible token deployed on the TRON Mainnet using the TRC-20 token standard.

2. Token Information

  • Token Name: TRC20 USDT.I
  • Symbol: USDT.I
  • Network: TRON Mainnet
  • Standard: TRC-20
  • Decimals: 6
  • Total Supply: 10,000,000,000 USDT.I

3. Smart Contract

Contract Address: THHRp9tTwFxmavCrtYLSsAV5HUHzN7ePh1

The token contract provides standard TRC-20 functionality including balance tracking, transfers, approvals, allowances and transferFrom operations.

4. Token Purpose

USDT.I is designed as a digital utility token for transfers and blockchain-based applications operating on the TRON network.

5. Decimal Precision

USDT.I uses 6 decimal places. One whole USDT.I token is represented by 1,000,000 base units on-chain.

6. Issuer

Issuer and deploying address: TSawUAYFzXgDLm1CRxMN1QckqSd6xtmUnw

7. Transparency

The smart contract address is publicly available on the TRON blockchain. Users and applications can independently inspect the contract and verify token balances and transactions on the network.

8. Independent Status

USDT.I is an independently issued token and is not the official Tether USD₮ token. The USDT.I name and symbol should not be interpreted as an affiliation with or endorsement by Tether.

9. Risk Notice

Digital assets involve risks. Token balances and transfers are recorded on the blockchain, while wallet display, token recognition and valuation may depend on individual wallet providers and blockchain indexing services.
